Research-oriented exploration of crystalline property prediction from crystallographic data, particularly CIF files. The workflow turns crystal structure information into a natural-language representation, encodes it with a transformer, and uses a regression head to predict crystalline properties.

**Technologies and concepts:** Python, deep learning, transformer architecture, T5 encoder, Hugging Face Transformers, pymatgen, Robocrystallographer, Materials Project API, CIF files, regression, crystal structure representation, and natural-language representation.

### 2. Retrieval-Augmented Heart Disease Classification

**Retrieval-Augmented Heart Disease Classification and Patient-Specific Risk Stratification using RosaNet and Agentic AI**

This project works with heart-sound / phonocardiogram (PCG) recordings. A deep-learning model performs cardiac disease classification. Retrieval then finds relevant information from an external knowledge base, and an LLM uses the retrieved information together with the model output to produce a contextual, patient-specific explanation. **The LLM is not presented as performing the medical diagnosis.**

**Pipeline:** heart-sound / PCG recording -> signal preprocessing -> noise reduction -> Butterworth filtering -> resampling -> standardization -> mel spectrogram -> RosaNet -> disease classification -> knowledge retrieval -> ChromaDB -> RAG -> LLM -> patient-specific explanation

**Technologies and concepts:** Python, TensorFlow, Keras, RosaNet, Librosa, Scikit-learn, FastAPI, LangChain, ChromaDB, OpenAI API, RAG, Agentic AI, mel spectrograms, audio signal processing, data augmentation, Butterworth filtering, spectral noise reduction, and explainable AI.
